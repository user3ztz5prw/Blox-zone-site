# Blox Zone — Site

Site estático responsivo para a marca Blox Zone.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — visual roxo/preto
- `script.js` — catálogo, busca, filtros e carrinho

## Personalização rápida
1. Abra `script.js` e altere a lista `products` para os anúncios que você realmente pretende publicar.
2. Em `index.html`, troque o link `https://discord.com/` pelo convite oficial do seu servidor.
3. Se quiser usar uma logo própria, substitua o bloco `BZ` do cabeçalho por uma imagem.
4. Publique os três arquivos em qualquer hospedagem de site estático.

## Importante
Este projeto é apenas a interface do site. Ele não processa pagamentos, não armazena credenciais e não entrega contas automaticamente. Antes de operar uma loja, confira as regras da Roblox e as leis aplicáveis.
